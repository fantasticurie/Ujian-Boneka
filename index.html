Cara 1: Install PWA ke Layar Utama (Tercepat)

  1. Buka web ini lewat Google Chrome di HP Android (wajib HTTPS / GitHub Pages / Vercel).
  2. Ketuk ikon Titik Tiga (⋮) di pojok kanan atas Chrome.
  3. Pilih "Tambahkan ke Layar utama" (Add to Home Screen) lalu klik Install.
  4. Buka Pengaturan HP > Aplikasi > Tasya Planner > Baterai, pilih "Tidak Dibatasi" (Unrestricted) agar Service Worker selalu aktif di background.

Cara 2: Bungkus Jadi File .APK (PWABuilder)

  1. Pastikan file index.html, manifest.json, dan sw.js sudah di-upload online (misal GitHub Pages / Netlify).
  2. Buka pwabuilder.com, masukkan URL web planner kamu, lalu klik Package for Stores > Android untuk mengunduh file .apk.
  3. Install APK tersebut di HP agar berjalan sebagai aplikasi Android mandiri dengan notifikasi bar penuh.
