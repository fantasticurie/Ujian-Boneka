Pengaturan Notifikasi Layar & Background

Pengingat otomatis H-3, H-2, H-1, & Hari-H muncul di layar walau web tidak dibuka

Status Izin Browser:

Mengecek...

Upload file sw.js & manifest.json ke folder web kamu agar notifikasi tetap berbunyi saat browser ditutup total.

Pengaturan di Laptop (Windows / Mac):

  • Pastikan mode Do Not Disturb / Focus Assist di Windows/Mac dalam keadaan OFF.
  • Klik ikon Gembok / Setelan situs di sebelah kiri URL browser → pastikan Notifications = Allow (Izinkan) dan Sound = Allow.
  • Biarkan tab tetap terbuka di background atau install sebagai PWA App agar alarm dan H-3/H-2/H-1 muncul otomatis di layar.

Agar Muncul di Layar HP Android:

  1. Buka link web kamu lewat Google Chrome di HP Android.
  2. Ketuk tombol Aktifkan di atas lalu tekan Izinkan (Allow).
  3. Ketuk menu Titik Tiga (⋮) di Chrome → pilih "Tambahkan ke Layar utama" (Add to Home Screen) → Install.
  4. Buka Pengaturan HP > Aplikasi > Tasya Planner > Baterai, pilih "Tidak Dibatasi" (Unrestricted).
